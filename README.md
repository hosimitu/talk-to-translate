# Talk-to-Translate

会話音声をローカル環境でリアルタイムに文字起こしし、必要に応じて翻訳を行うWindowsデスクトップアプリケーションです。

## 主な特徴
- **ローカル文字起こし**: `faster-whisper` を使用し、PCローカルで安全かつ高速に音声認識を実行。
- **モデル選択**: PCのスペックや用途に合わせてモデルサイズ（`tiny`, `base`, `small`）を選択可能。
- **複数言語対応**: 日本語、英語、中国語などの音声を認識・文字起こし。
- **リアルタイム翻訳**: Google翻訳等のオンラインAPI（`deep-translator`）と連携し、文字起こし結果を即座に翻訳。
- **モダンなUI**: `CustomTkinter` による直感的で洗練されたデスクトップGUI。ワンクリックでのコピー機能付き。
- **マイク選択**: 複数の入力デバイスから使用するマイクをアプリ内で切り替え可能。

## 想定環境
- OS: Windows 11
- Python: 3.10+
- 推奨スペック: Intel Core i5 / AMD Ryzen 5 以上、メモリ 8GB 以上
