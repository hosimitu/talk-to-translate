# Talk-to-Translate

会話音声をローカル環境でリアルタイムに文字起こしし、必要に応じて多言語へ翻訳を行うWindowsデスクトップアプリケーションです。

一般的なノートパソコン（CPUのみ、メモリ8GB〜）でも軽快に動作するよう設計されています。

---

## 🌟 主な特徴

- **超高速＆高精度な文字起こしエンジン**:
  - **`SenseVoice-Small`（メイン推奨・ONNX int8）**: Alibaba開発の東アジア言語特化モデル。日本語・中国語・英語で圧倒的な認識精度を誇り、Whisperの約5〜10倍の超爆速（数十〜百ミリ秒）で即座に文字起こしを完了。
  - **`Whisper: large-v3-turbo`**: OpenAI系最高峰の汎用モデル（バックアップ用）。
  - **`Whisper: small`**: 軽量なWhisperモデル。
  - **音源分離（MossFormer2・ON/OFF制御）**: 複数人が同時に話した音声をAIで2人に分離し、それぞれ「[話者1]」「[話者2]」として個別に出力可能（チェックボックスでオンデマンド切り替え）。
  - **自動音量ノーマライズ＆DCオフセット補正**: マイクからの音声波形をリアルタイムに最適化し、声が小さい・遠い場合でも明瞭に認識。
  - **VAD（音声区間検出）**: 無音区間を自動スキップし、誤認識・ハルシネーションを抑制。
- **多言語対応 & 自動言語検出**:
  - 日本語、英語、中国語に対応。
  - **自動検出 (auto)** を標準サポートし、会話中に言語が混ざっても自動認識。
- **選べるリアルタイム翻訳方式（クラウド / ローカルAI）＆文脈補完バッファリング**:
  - **`クラウド翻訳 (Google/MyMemory) (推奨)` [デフォルト]**: 高速かつ追加ダウンロードなしで利用可能。レート制限時は自動でMyMemory翻訳へフェイルオーバー。
  - **`ローカルAI (NLLB-200 600M / 1.3B 推奨)`**: MetaのNLLB-200モデルをCTranslate2（int8量子化）で高速推論。同一フレーズのループ防止機能を備え、完全オフライン・API制限なしで英語・中国語・日本語を双方向に高精度翻訳。
  - **文脈を保つ小バッファリング翻訳**: 音声認識の息継ぎによる細切れ断片を2〜3行（または発話休止2秒）単位で自然に結合して翻訳し、主語の脱落や係り受けの破綻を大幅に低減。
- **直感的な2ペインUI**:
  - `CustomTkinter` によるモダンなダークテーマ画面。
  - 翻訳エンジン（クラウド/ローカルAI）をワンクリックで切り替え可能。
  - 文字起こし結果と翻訳結果を左右に独立表示。
  - 自動最下部スクロール対応＆ワンクリックの **「コピー」** ボタンをそれぞれに完備。
- **マイク選択機能**:
  - PCに接続されているマイク（入力デバイス）をアプリ内で自由に切り替え可能。
- **設定の自動保存・復元（永続化）**:
  - 選択した文字起こしモデル、翻訳エンジン/モデル、入力言語、翻訳先言語、マイクデバイス、音源分離のON/OFFが自動保存（`config.json`）され、次回起動時に前回の設定が自動で復元されます。EXE実行時や管理者権限フォルダでも安全に動作します。

## 💻 動作環境

- **OS**: Windows 11 (Windows 10でも動作可)
- **Python**: 3.10 以上 (Python 3.14 検証済み)
- **基本ハードウェア推奨**: Intel Core i5 / AMD Ryzen 5 以上、メモリ 8GB 以上

### 📊 モデル組み合わせ別 スペック要件一覧

本アプリは、選択する「文字起こしモデル」「翻訳エンジン」「音源分離の有無」によって必要なハードウェア性能や体感速度が異なります。ご利用のPC環境に合わせて最適な構成を選択してください。

| レベル / 用途 | 文字起こし | 翻訳エンジン | 音源分離 | 必要最低スペック | 推奨スペック | レイテンシ (体感速度) |
| :--- | :--- | :--- | :---: | :--- | :--- | :---: |
| **① 標準・超軽量**<br>*(最もおすすめ)* | **SenseVoice-Small** | **クラウド翻訳** | OFF | **CPU**: 2コア (Core i3〜)<br>**RAM**: 4GB〜8GB<br>**GPU**: 不要 | **CPU**: Core i5 / Ryzen 5<br>**RAM**: 8GB<br>**GPU**: 不要 | **⚡ 超高速**<br>(0.1〜0.5秒) |
| **② 完全オフライン<br>(軽量ローカル)** | **SenseVoice-Small** | **NLLB 600M** | OFF | **CPU**: 4コア (Core i5〜)<br>**RAM**: 8GB<br>**GPU**: 不要 | **CPU**: Core i5 / Ryzen 5<br>**RAM**: 16GB<br>**GPU**: あれば尚良 (VRAM 2GB) | **🚀 高速**<br>(0.3〜1.0秒) |
| **③ 高精度ローカル<br>(文脈重視・バランス)** | **SenseVoice-Small** | **NLLB 1.3B** | OFF | **CPU**: 4〜6コア<br>**RAM**: 8GB〜16GB<br>**GPU**: 不要 (CPU可) | **CPU**: 6コア以上<br>**RAM**: 16GB<br>**GPU**: NVIDIA (VRAM 4GB〜) | **◯ 実用速度**<br>(CPU: 1〜2秒 /<br>GPU: 0.3〜0.6秒) |
| **④ 複数人・会議特化<br>(音源分離ON)** | **SenseVoice-Small** | **クラウド** または<br>**NLLB 600M** | **ON** | **CPU**: 4コア (Core i5〜)<br>**RAM**: 8GB〜16GB<br>**GPU**: 不要 | **CPU**: Core i7 / Ryzen 7<br>**RAM**: 16GB<br>**GPU**: NVIDIA (VRAM 4GB〜) | **◯ 実用速度**<br>(1〜2秒) |
| **⑤ 高精度文字起こし<br>(Whisper併用)** | **Whisper<br>large-v3-turbo** | **クラウド** または<br>**NLLB 600M/1.3B** | 任意 | **CPU**: 6コア (Core i7〜)<br>**RAM**: 16GB<br>**GPU**: 推奨 | **CPU**: 8コア以上<br>**RAM**: 16GB〜32GB<br>**GPU**: NVIDIA (VRAM 6GB〜) | **△ やや待つ**<br>(CPU: 2〜4秒 /<br>GPU: 0.5〜1秒) |
| **⑥ 最高峰ローカル<br>(ヘビー級)** | **Whisper<br>large-v3-turbo** | **NLLB 3.3B** | **ON** | **CPU**: 8コア以上<br>**RAM**: 16GB<br>**GPU**: NVIDIA必須 | **CPU**: Core i7/i9, Ryzen 7/9<br>**RAM**: 32GB<br>**GPU**: NVIDIA (VRAM 8GB〜12GB) | **⚠️ GPU必須**<br>(CPUでは10〜30秒以上かかり会話が成立しない) |

> [!TIP]
> - **一般的なビジネスノートPC（CPUのみ、メモリ8GB〜16GB）**: **レベル①** または **レベル②/③** が最も軽快で快適です。
> - **GPU搭載PC（GeForce RTXシリーズ等、VRAM 4GB以上）**: **音源分離ON** や **NLLB 1.3B**、**Whisper large-v3-turbo** もストレスなく高速動作します。

## 🚀 クイックスタート

### 📦 方法1: リリース版をダウンロードしてすぐ使う（最もおすすめ・Python不要）

Pythonのインストールや環境構築は不要です。Windows PCがあればすぐに使い始めることができます。

1. **[GitHub Releases (最新リリース)](https://github.com/hosimitu/talk-to-translate/releases/latest)** を開きます。
2. ページ下部の Assets から **`Talk-to-Translate-vX.X.X-windows-x64.zip`** をダウンロードします。
3. ダウンロードした ZIP ファイルを右クリックして「すべて展開」で解凍します。
4. 解凍されたフォルダ内の **`Talk-to-Translate.exe`** をダブルクリックするだけで、コマンド画面なしにアプリが起動します。
   （※デスクトップ等にショートカットを作成しておくと便利です）

---

### 🛠️ 方法2: ソースコードから動かす場合（開発者向け）

Python環境で直接スクリプトを実行したり、自身でコードをカスタマイズ・再ビルドしたい場合の手順です。

#### 1. リポジトリのクローン
```bash
git clone https://github.com/hosimitu/talk-to-translate.git
cd talk-to-translate
```

#### 2. 仮想環境の作成とパッケージのインストール
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

#### 3. アプリケーションの起動
- **通常起動**:
  ```powershell
  python main.py
  # または run.bat をダブルクリック
  ```
- **EXEの独自ビルド**:
  ```powershell
  python build_exe.py
  ```
  実行すると `dist\Talk-to-Translate\` 配下にスタンドアロンEXEが生成されます。

## 📖 使い方

1. **設定（上部パネル）**:
   - **マイクデバイス**: 使用するマイクを選択します。
   - **AIモデル**: お使いのPCスペックに合わせて選択（SenseVoice-Small 推奨）。
   - **入力言語**: 通常は `自動検出 (auto)` のままでOKです。
   - **翻訳先言語**: 翻訳したい言語（英語、日本語、中国語）を選択します。
   - **翻訳エンジン**: `クラウド翻訳 (Google/MyMemory) (推奨)` または `ローカル翻訳 (NLLB 600M / 1.3B 推奨)` を選択します（デフォルトはクラウド）。
2. **録音開始**:
   - 下部の緑色の **「録音開始」** ボタンをクリックします（ボタンが赤色の「録音停止」に変わります）。
   - 初回起動時のみ、選択したAIモデルが自動ダウンロードされます。
3. **会話と確認**:
   - マイクに向かって話すと、約3秒ごとに左側の **「🎙️ 文字起こし結果」** にテキストが追記されます。
   - 同時に右側の **「🌐 翻訳結果」** に翻訳テキストが自動表示されます。
4. **コピー・消去**:
   - 各テキストボックス右上の **「コピー」** ボタンをクリックすると、クリップボードにコピーされます。
   - 下部の **「テキスト全消去」** ボタンで、表示中のテキストをクリアできます。

## 🗑️ アンインストール

本アプリケーションは、Windowsのレジストリやシステムディレクトリを変更しないポータブル構成となっています。そのため、通常のアンインストールは **フォルダを削除するだけ** で完了します。

### 1. 通常のアンインストール

- **リリース版（ZIP版）をご利用の場合**:
  - 解凍した `Talk-to-Translate` フォルダをそのまま削除（ゴミ箱へ移動）してください。
- **ソースコード版をご利用の場合**:
  - クローンしたリポジトリフォルダ（および作成した `.venv` 仮想環境）を削除してください。

### 2. 完全削除（設定ファイル・モデルキャッシュの消去）

使用中に自動保存された設定ファイルや、初回実行時にダウンロードされたAIモデルのキャッシュも含めてPC内から完全に消去したい場合は、以下のフォルダも手動で削除してください。

| 対象データ | 保存場所 (エクスプローラーのアドレスバーに入力) | 内容 |
| :--- | :--- | :--- |
| **設定ファイル** | `%APPDATA%\Talk-to-Translate` | UIの設定保存ファイル (`config.json`) ※存在する場合のみ |
| **AIモデルキャッシュ** | `%USERPROFILE%\.cache\huggingface` | SenseVoice / Whisper等のダウンロード済み音声認識モデル |
| **ローカル翻訳モデル** | アプリフォルダ内の `checkpoints\` | NLLB翻訳モデル（アプリフォルダ削除時に同時に削除されます） |

> [!NOTE]
> `%USERPROFILE%\.cache\huggingface` には他のPython AIツールでダウンロードしたモデルが同居している場合があります。Talk-to-Translateで使用したモデルのみを削除したい場合は、`hub` フォルダ内の `models--csukuangfj--sherpa-onnx-sense-voice...` や `models--Systran--faster-whisper...` を個別に削除してください。
