# Talk-to-Translate

会話音声をローカル環境でリアルタイムに文字起こしし、必要に応じて多言語へ翻訳を行うWindowsデスクトップアプリケーションです。

一般的なノートパソコン（CPUのみ、メモリ8GB〜）でも軽快に動作するよう設計されています。

---

## 🌟 主な特徴

- **完全ローカル文字起こし**:
  - `faster-whisper` を採用。GPU（グラフィックボード）がなくてもCPUで高速に動作（int8量子化）。
  - **VAD（音声区間検出）**: 無音区間を自動スキップし、誤認識・ハルシネーションを抑制。
- **モデル選択**:
  - `tiny (最速・軽量)`: 低スペックPC向け、遅延が最も少ない。
  - `base (標準)`: 速度と精度のバランスが最も良いデフォルトモデル。
  - `small (高精度)`: より正確な文字起こしを行いたい場合（CPUリソースをやや消費）。
- **多言語対応 & 自動言語検出**:
  - 日本語、英語、中国語に対応。
  - **自動検出 (auto)** を標準サポートし、会話中に言語が混ざっても自動認識。
- **リアルタイム翻訳（完全無料）**:
  - Google翻訳エンドポイント（`deep-translator`）を利用し、文字起こしされたテキストを即座に翻訳。
  - Google側でレート制限等が発生した場合は自動的に **MyMemory翻訳へフォールバック** する高可用性設計。
- **直感的な2ペインUI**:
  - `CustomTkinter` によるモダンなダークテーマ画面。
  - 文字起こし結果と翻訳結果を左右に独立表示。
  - 自動最下部スクロール対応＆ワンクリックの **「コピー」** ボタンをそれぞれに完備。
- **マイク選択機能**:
  - PCに接続されているマイク（入力デバイス）をアプリ内で自由に切り替え可能。

---

## 💻 動作環境

- **OS**: Windows 11 (Windows 10でも動作可)
- **Python**: 3.10 以上 (Python 3.14 検証済み)
- **ハードウェア推奨**: Intel Core i5 / AMD Ryzen 5 以上、メモリ 8GB 以上

## 🚀 クイックスタート

### 1. リポジトリのクローン
```bash
git clone https://github.com/hosimitu/talk-to-translate.git
cd talk-to-translate
```

### 2. 仮想環境の作成とパッケージのインストール
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 3. アプリケーションの起動
```powershell
python main.py
```

## 📖 使い方

1. **設定（上部パネル）**:
   - **マイクデバイス**: 使用するマイクを選択します。
   - **AIモデル**: お使いのPCスペックに合わせて選択（通常は `base` を推奨）。
   - **入力言語**: 通常は `自動検出 (auto)` のままでOKです。
   - **翻訳先言語**: 翻訳したい言語（英語、日本語、中国語）を選択します。
2. **録音開始**:
   - 下部の緑色の **「録音開始」** ボタンをクリックします（ボタンが赤色の「録音停止」に変わります）。
   - 初回起動時のみ、選択したAIモデルが自動ダウンロードされます。
3. **会話と確認**:
   - マイクに向かって話すと、約3秒ごとに左側の **「🎙️ 文字起こし結果」** にテキストが追記されます。
   - 同時に右側の **「🌐 翻訳結果」** に翻訳テキストが自動表示されます。
4. **コピー・消去**:
   - 各テキストボックス右上の **「コピー」** ボタンをクリックすると、クリップボードにコピーされます。
   - 下部の **「テキスト全消去」** ボタンで、表示中のテキストをクリアできます。
